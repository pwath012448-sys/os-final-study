ติว OS Final แบบเข้าใจจริง แล้วทำข้อสอบได้

เว็บนี้ทำจากคลิปที่อาจารย์บอกแนวข้อสอบ (16 ต.ค. 2026) และชีทของอาจารย์ทั้ง 5 ไฟล์ ทุกเรื่องมีภาพสไลด์จริงพร้อมบอกว่าอยู่หน้าไหน มีปุ่มฟังเสียงอาจารย์ตรงช่วงที่พูด มีเครื่องมือให้ลองกดเอง และมีแบบฝึกหัดที่ตรวจคำตอบให้ทันที

❓ จำนวนข้อยังไม่ประกาศ อาจารย์จะออกข้อสอบใกล้วันสอบเพื่อกันข้อสอบรั่ว
📚 ขอบเขตชีท 2.4 Deadlock, 3.1 Memory, 3.2 Virtual Memory, 3.3 Storage และ 4.1–4.2 File & Protection

ใช้เว็บนี้ยังไง

📄 สไลด์อาจารย์ทุกภาพบอกชื่อไฟล์ · หน้าในชีท · หน้า PDF · เลขรูป กดที่ภาพเพื่อขยาย หรือกด "เปิด PDF หน้านี้" เพื่อดูไฟล์จริง
💡 เข้าใจง่ายๆเปรียบเทียบกับเรื่องใกล้ตัว แล้วค่อยเข้าสู่นิยามแบบที่ต้องเขียนในข้อสอบ
🕹 ลองเองเครื่องมือจำลองทีละขั้น เช่น page replacement (มีโหมดให้เราทายเอง), Banker's, RAG, disk
